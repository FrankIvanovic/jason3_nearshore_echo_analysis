# Echo_Simulation — 基于 PM 谱海面的高度计海洋回波仿真

卫星雷达高度计（Jason-3 / Ku 波段）海面回波波形仿真，复现参考文献
《基于电磁散射特性的雷达高度计回波仿真与分析》（华中科技大学硕士学位论文）
第四章的逐面元时域法，并以第五章 Brown 平均回波模型作解析对照验证。

## 物理模型链

```
PM 方向谱 ──FFT线性滤波──> 随机海面 η(x,y) ──逐面元散射/雷达方程──> 104 门回波波形
(式2.14-2.17)               (式2.15: U10→U19.5)      (式4.1-4.10)        ↑
                                                        雷达点目标响应 sinc² ┘ (式5.4)
Brown 模型: W(t) = P_FS(t) ∗ q_s(η) ∗ S_r(τ)  (式5.1-5.4) —— 解析对照基准
```

| 环节 | 模型 | 公式出处 |
|---|---|---|
| 海面 | 二维方向 PM 谱, W ∝ K⁻⁴exp(−βg²/K²U⁴)cos²(θₖ−φᵥ)/π | 论文式(2.14)-(2.17) |
| 散射 | GO: σ⁰ = ρπp(tanθ,0)/cos⁴θ, 各向异性 Cox-Munk 斜率 PDF | 论文式(4.5)-(4.10) |
| 雷达 | 逐面元 λ²PtG²σ⁰dS/((4π)³R⁴) 按双程延迟 2R/c 分箱累加 | 论文式(4.1)-(4.4) |
| 系统 | 点目标响应 (sin(πBτ)/(πBτ))², B=320 MHz | 论文式(5.4) |
| 对照 | Brown 卷积模型（数值实现, 空间截断与仿真一致） | 论文式(5.1)-(5.4) |

系统参数（`altimeter_params.py`）: H=1336 km, 13.575 GHz, Pt=50 W,
波束宽度 2.2°（论文口径）, 104 距离门 × 3.125 ns（与 Jason SGDR Ku 波段一致）,
海水 Debye 介电常数 (47.0823, 39.0651) → ρ=0.6173。

## 两尺度口径（重要）

PM 网格（dx≈15.6 m）只解析长重力波；短波对 σ⁰ 的贡献由含全部波段的
Cox-Munk 斜率统计（式 4.9/4.10）承载, 波高/延迟分布由 PM 长波海面承载。
有限网格对 PM 方差的解析比例 capture = exp(−βg²/(k_max²U⁴))，
U19.5 = 8/12/16 m/s 时约为 65%/92%/97%；海面高度场默认归一化到完整 PM
理论 σ_h（SWH=4σ_h）以补偿截断。**低风速（U19.5 < 6 m/s）时解析比例骤降,
需改用两尺度分解, 当前版本不适用。**

`use_local_tilt` 选项控制长波倾斜是否调制局部入射角:
`False`（默认）与 Brown 模型假设严格一致, 用于正确性验证;
`True` 给出长波倾斜对 σ⁰ 的调制（两尺度二阶效应）。

## 使用

```bash
python run_ocean_echo_sim.py            # 完整运行 (2048² × 24 实现 × 3 风速, 约 2-3 min)
python run_ocean_echo_sim.py --quick    # 冒烟自检 (512² × 4)
```

## 近海复合场景（第二期）

`coastal.py` + `dielectric.py` + `run_coastal_echo_sim.py` 实现论文 4.3 节的
近海复合粗糙面回波与海况参数敏感性:

| 场景 | 内容 | 论文对照 |
|---|---|---|
| A | 论文呈现风格波形（单实现逐门折线+散斑, U19.5=4/8/12） | 图 4.3 |
| B | 沙滩条带占比 0–80%: 尾窗先于平台响应（远区先被陆地填充） | 4.3.1 / 图 4.10 |
| C | 2 km 方形礁石位于天底点/2.2/4.4/8.8 km（+2 m, 回波提前） | 4.3.2 / 图 4.11 |
| D | 半径 1.5 km 圆形岛屿位于天底点/2.2/4.4/6.6 km（dB 尺度显示弱回波） | 4.3.3 / 图 4.12 |
| E | 盐度/温度 → Debye 介电常数（式 2.20-2.23）→ ρ → 平台功率 | 2.4.1 节 |

陆地采用**两尺度口径**: 陆地微粗糙（指数谱, 式 2.18/2.19, l=1.5λ≈3.3 cm）远小于
面元 dx≈15.6 m, 不显式生成高度场 —— 面元尺度上是海拔平台（改变延迟）, 微粗糙
通过指数谱斜率方差（截断 k_cut=2π/λ）的各向同性 GO σ⁰ 体现。由此:
沙滩/礁石（σ=0.1λ）σ⁰(0)≈14.6 dB 高于海面, 岛屿（σ=0.5λ）σ⁰(0)≈0.6 dB 低于
海面, 与论文图 4.10-4.12 的定性特征一致。k_cut 若取 π/λ 陆地 σ⁰ 约降 4 dB
（截断口径敏感性）。

海水介电常数模块 `dielectric.seawater_eps(S,T,f)` 在论文锚点
(13.575 GHz, 20°C, 35‰) 复现 ε=(47.08, 39.07)、ρ=0.6173。敏感性结论:
**Ku 波段回波对盐度不敏感**（0–40‰ 全程 <0.005 dB）, 温度影响约 0.2 dB
（−2~30°C）—— 这正是盐度遥感需 L/C 波段而高度计可忽略盐度修正的物理依据。

```bash
python run_coastal_echo_sim.py           # 完整 (2048² × M=6, 约 70 s)
python run_coastal_echo_sim.py --quick   # 冒烟 (512² × M=2)
```
