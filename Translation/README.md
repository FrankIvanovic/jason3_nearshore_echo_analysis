# 参考文献译文本

毕业设计要求的外文参考文献中文翻译。两篇译文各设一个分支（均自 `Translation` 分支分出；因 git 不允许 `Translation/xxx` 与 `Translation` 分支并存，子分支用连字符命名），切换到对应分支即可在工作区看到译文目录：

- `Translation-brown1977` — Brown 1977《粗糙表面的平均冲激响应及其应用》，位于 `brown1977/` 目录
- `Translation-hayne1980` — Hayne 1980《近正入射海面散射的雷达高度计平均回波波形》，位于 `hayne1980/` 目录

每个目录内含 LaTeX 译本源文件（封面格式同学院译文本模板）、插图、编译好的 PDF，文末附参考文献原文页。

所选外文原文 PDF 见仓库根目录 `参考文献/`（该目录含大量原始文献与数据，不入库）。
